## Global rules for every task

- TDD: write the Luau test, run it and see it fail, implement, run it green, then the full
  suite. Single file: `./run-tests tests/<name>.test.luau`. Full suite: `./run-tests > /tmp/daybar-v5.log 2>&1; echo "EXIT=$?"; grep -E "[0-9]+ passed, [0-9]+ failed" /tmp/daybar-v5.log`.
  Read the `N passed, M failed` line and the `guards:` line; never trust a piped exit code.
- `lib/**/*.luau` is pure: no `noctalia`, `barWidget`, `panel`, `desktopWidget`, `ui` globals.
  Each module returns one table. Lib modules require siblings with the host form
  `require("./x.luau")` / `require("../x.luau")`. Tests load them with
  `modules.load("lib/x.luau")`.
- `views/*.luau` are UI builders shared by entries: they may use `ui` and `noctalia.tr`, never
  I/O. Entries (`service.luau`, `widget.luau`, `toolbar.luau`, `capture.luau`, `note.luau`,
  `clockpin.luau`, `clockdesk.luau`) are thin.
- Port rule (v4 JS → Luau): same function names (camelCase), same behavior, same test cases.
  A JS `Date` parameter or return value becomes **epoch seconds in local time** (a number);
  numbers that were milliseconds in v4 stay milliseconds. `null`/`undefined` → `nil`;
  arrays are 1-based sequences; `Object.assign({}, a, b)` → a shallow copy helper
  (`lib/tbl.luau`, Task 3). Regex → Lua patterns or hand-written scanners; when a pattern
  cannot express the v4 regex, write a small scanner and test the v4 cases.
- Luau pitfalls: `end` is a keyword (`endTime`, `endDate`, `endsAtMs`); storing `nil` deletes
  a key; `""` and `0` are truthy; `#t` is only safe on sequences; `table.insert(t, string.gsub(...))`
  passes two values (wrap the gsub in parentheses); `os.time{...}` normalizes overflowing
  fields (use it for day arithmetic); `os.date("*t", secs)` is local time.
- Forbidden in plugin code (root `*.luau`, `lib/**`, `views/**`): `load`, `loadstring`,
  `getfenv`, `setfenv`, and string-form `noctalia.runAsync`/`runStream`/`runInTerminal`.
  `tests/guards.test.sh` enforces it (Task 1, extended in Task 15).
- Never write a real email, token or `/home/<user>` path in code, tests or docs; use `~`.
- English code and comments. UI strings via `noctalia.tr`/`trp` with both translation files.
- No reference to any previous or source project (the forked pomodoro MIT notice in
  `THIRD_PARTY.md` is the only allowed attribution).
- **DO NOT run any git commands (commit, push, branch, merge, add). DO NOT invoke the
  git-commit skill.** The orchestrator commits per task (`/rpi:implement` contract).

## Shared shapes

### Time

- Instants inside lib: epoch seconds (local time semantics via `os.date`/`os.time`).
- Dates `"YYYY-MM-DD"`, times `"HH:MM"` (as v4).
- Clock deadlines in the view: `endsAtMs` (epoch ms, from `noctalia.nowMs()`).

### Event (from `lib/khalread.luau`, same as the v4 CalendarService shape plus extras)

The v4 event field `end` is a Luau keyword only as an identifier, not as a string key.
Events keep the v4 shape so the ported modules stay one to one: `ev["end"]` is legal Luau and
JSON-safe. Rule: **read and write it as `ev["end"]`**, never `ev.end` (syntax error).

```lua
{
  uid = "abc@google.com", calendar = "Eventos", summary = "Review",
  start = 1791640800, ["end"] = 1791644400,      -- epoch seconds, all-day end exclusive
  allDay = false, location = "", url = "", description = "", repeats = false,
}
```

### Data (`data.json`, schema v2, unchanged from v4)

```lua
{
  version = 2, tasks = {}, eventChecks = {}, reminders = {}, bookmarks = {}, notes = {},
  focusLog = {}, recentTimers = {}, ui = { lastTab = "", clockOverlay = false },
}
```

### View (service → entries, `noctalia.state` key `view`)

```lua
{
  rev = 12,                       -- increments on every publish
  now = 1791662400000,            -- epoch ms at publish
  data = <Data without version>,  -- bookmarks carry `thumbPath` when the file exists
  settings = { work_duration = 25, ..., fetch_previews = true },
  calendar = { available = true, calendars = { "Eventos" }, events = { <Event> },
               from = "2026-10-02", to = "2026-11-16", writing = false, syncFailed = false,
               loading = false },
  pomodoro = { mode = 0, running = false, started = false, remaining = 1500,
               endsAtMs = nil, completed = 0, linkedTaskId = nil, total = 1500 },
  timer = { set = false, running = false, remaining = 0, total = 0, endsAtMs = nil, label = "" },
  alarmSource = "",               -- "pomodoro" | "timer" | ""
  focusPanel = "pomodoro",        -- Focus tab view: "pomodoro" | "timer"
  requestedTab = nil,             -- consumed by the toolbar on open
  details = { ["<uid>"] = { people = {...}, meetUrl = "", location = "" } },
  deleting = { ["<uid>"] = { phase = "locating" | "ready" | "error", recurring = false, error = nil } },
}
```

### Commands (entry → service, AD-202)

`noctalia.state` key `cmd.<entry>` (entries: `bar`, `toolbar`, `capture`, `note`, `clockpin`,
`clockdesk`) holds a sequence `{ { seq, name, args }, ... }`. The service answers on
`ack.<entry> = { seq, ok, error, result }`. `lib/outbox.luau` (Task 14) holds both sides.

Command names: `addTask`, `toggleTask`, `deleteTask`, `renameTask`, `toggleEvent`,
`setLastTab`, `commit` (capture), `addBookmark`, `refreshBookmark`, `renameBookmark`,
`deleteBookmark`, `openUrl`, `copyText`, `saveNote`, `deleteNote`, `pomodoro`
(`{ action = "toggle" | "start" | "pause" | "skip" | "reset" | "setMode", mode? }`),
`timer` (`{ action = "set" | "toggle" | "reset" | "preset", text?, seconds? }`),
`setFocusPanel`, `linkTask`, `setClockOverlay`, `loadRange`, `locateEvent`, `deleteEvent`,
`cancelDelete`, `loadDetails`, `reloadCalendar`, `openSettings`.

```bash
#!/usr/bin/env bash
# Static guards over plugin code (root *.luau, lib/, views/). The test harness is exempt.
set -eo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "$ROOT"
mapfile -t files < <(find . -maxdepth 1 -name '*.luau'; find lib views -name '*.luau' 2>/dev/null)
fail=0
if ((${#files[@]})); then
  if grep -nE '\b(loadstring|getfenv|setfenv)\b|(^|[^.:A-Za-z_])load[[:space:]]*\(' "${files[@]}"; then
    echo "guards: dynamic code evaluation is forbidden" >&2; fail=1
  fi
  if grep -nE 'noctalia\.(runAsync|runStream|runInTerminal)\([[:space:]]*["'"'"'[]' "${files[@]}"; then
    echo "guards: external commands must be argv tables" >&2; fail=1
  fi
fi
if grep -rniE 'n[i]ko' --exclude-dir=.git --exclude-dir=node_modules --exclude-dir=.generated . >/dev/null; then
  echo "guards: reference to a previous project found" >&2; fail=1
fi
((fail == 0)) && echo "guards: ok"
exit "$fail"
```
